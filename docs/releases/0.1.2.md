# Pulse 0.1.2 release notes

Pulse 0.1.2 is the supported patch update for an installed Pulse 0.1.1 system. It packages the production quote-lifecycle hotfixes that followed the 0.1.1 tag together with the new project, quote, change-order, and expense lifecycle.

## Production hotfixes included

- Corrects dashboard lifecycle dates and keeps quote preparation deadlines separate from downstream delivery dates.
- Finalizes the audited quote-sent workflow: marking a quote sent records the exact lifecycle event, locks financial values, removes its preparation deadline from active dashboard analysis, and retains the Administrator recovery path.

## Project and change-order lifecycle

- Creates a project only through an approved original quote handoff. Approval and project creation occur atomically.
- Lets an active project create blank change-order quotes that inherit the project client, contact, site, assignee, lifecycle context, request context, trades, and quote calculation mode.
- Connects approved change orders back to the original project and includes only approved quote snapshots in project financial totals.
- Lets an imported quote be approved as a change order and attached to an active existing project for the same client instead of creating a duplicate project.
- Adds reciprocal navigation: every project shows its original quote and sequenced change orders, while every linked quote points back to the project.
- Extends inherited files and updates across every quote connected to the same project.

## Project workspace redesign

- Reworks the project workspace to follow the quote workspace's Work, Details, Files, and Updates structure.
- Adds two three-zone financial meters: estimated cost against approved sales price, and actual expense burn against approved estimated cost.
- Adds approved sales, estimated cost, actual expense, planned gross profit, and remaining cost allowance metrics with clear overrun states.
- Adds a project expense ledger with create, edit, archive, category, vendor, date, description, amount, and optional receipt linkage.
- Adds editable project contact, site, assignment, collaborators, planned start, target completion, and shared lifecycle details.
- Removes standalone project creation from the project queue and adds a direct Create change order action inside active projects.

## Database update

The normal installer update runs `prisma migrate deploy` with the restricted migration identity. It applies one additive forward migration after the six migrations shipped through 0.1.1:

1. `202608070001_project_quote_change_orders` creates the `ProjectQuote` and `ProjectExpense` tables, adds their indexes and constraints, and backfills every existing quote-linked project with one original quote relationship.

The migration retains the existing project quote snapshot fields as a compatibility mirror during this release. It does not delete projects, quotes, documents, invoices, or expenses and never uses `prisma db push`, `prisma migrate reset`, or a destructive down migration.

## Supported Windows upgrade

- Supported source release: Pulse 0.1.1.
- Target release: Pulse 0.1.2.
- Installer AppId: unchanged.
- Compose project: `pulse-production`.
- Default persistent volumes: `pulse-production-postgres` and `pulse-production-minio`.

Before updating, retain the verified encrypted backup outside the Pulse machine. After installation, verify Administrator login, quote sent behavior, original-quote approval handoff, change-order creation and approval, reciprocal navigation, the financial meters, expense entry, and inherited files and updates.

## Signing and integrity

Use the installer and `.sha256` file attached to the `v0.1.2` GitHub release, not the source archives. Prefer an Authenticode-signed installer. If the release is unsigned, verify its SHA-256 through an independently trusted channel before running it as Administrator.
